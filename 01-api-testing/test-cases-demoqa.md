# Тест-кейсы: API авторизации demoqa.com

## TC-LOGIN-01 — Успешный вход (позитивный)

| Поле | Значение |
|---|---|
| ID | TC-LOGIN-01 |
| Название | Проверка успешной авторизации с корректными данными |
| Предусловие | Пользователь зарегистрирован на demoqa.com |
| Приоритет | Высокий |

**Шаги:**
1. Открыть форму входа: https://demoqa.com/login
2. Ввести корректный логин и пароль
3. Нажать кнопку "Login"
4. В DevTools (вкладка Network) найти запрос к /Account/v1/Login
5. Проверить, что статус ответа — 200 OK
6. Проверить, что в теле ответа присутствуют token и userId

**Ожидаемый результат:** пользователь входит в систему; сервер возвращает 200 OK, token и userId.

**Фактический результат:** совпадает с ожидаемым. Статус: Пройден.

## TC-LOGIN-02 — Вход с неверным паролем (негативный)

| Поле | Значение |
|---|---|
| ID | TC-LOGIN-02 |
| Название | Проверка обработки неверного пароля |
| Предусловие | Пользователь зарегистрирован, вводит неправильный пароль |
| Приоритет | Высокий |

**Шаги:**
1. Открыть форму входа: https://demoqa.com/login
2. Ввести корректный логин
3. Ввести неверный пароль
4. Нажать кнопку "Login"
5. В DevTools найти запрос /Account/v1/Login, проверить статус и тело ответа

**Ожидаемый результат:** сообщение "Неверное имя пользователя или пароль!"; статус ответа — 401 Unauthorized.

**Фактический результат:** сообщение отображается корректно, но статус ответа — 200 OK.

**Статус:** Провален (обнаружен дефект, см. bug-report-login-status.md).
