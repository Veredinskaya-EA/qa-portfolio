## Примеры выполненных заданий

### Задание 26. CHECK-ограничение

```sql
CREATE TABLE employees (
    id  INT PRIMARY KEY,
    name VARCHAR(50),
    age INT CHECK (age >= 18)
);
```

Ограничение запрещает вставку строки, в которой возраст меньше 18 лет: СУБД проверяет условие на уровне схемы, а не на уровне приложения.

### Задание 15. Ограничение уникальности

