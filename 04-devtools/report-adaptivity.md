# Отчет по тестированию адаптивности веб-интерфейса

## Зачетное задание. Вариант 2

**Автор:** Верединская Екатерина Александровна

---

## Цель тестирования

Проверка корректности отображения веб-интерфейса при различных размерах экрана и настройках масштабирования.

## Объект тестирования

Веб-интерфейс приложения Book Store (https://demoqa.com)

## Инструменты тестирования

* Браузер Chrome/Edge
* DevTools (вкладка **Rendering**, Device Toolbar `Ctrl+Shift+M`)
* Postman (для проверки API при разных условиях)

## Методология тестирования

Тестирование проводилось по следующим параметрам:

* Проверка отображения на различных разрешениях экрана
* Тестирование при изменении масштаба страницы
* Проверка корректности работы элементов управления
* Анализ поведения адаптивных компонентов

---

## Результаты тестирования

### Проверка на мобильных устройствах

**Разрешение 320x480**

* Все элементы интерфейса корректно масштабируются
* Навигация работает корректно
* Кнопки и ссылки доступны для нажатия

**Разрешение 360x640**

* Меню корректно сворачивается в гамбургер
* Формы ввода адаптируются под размер экрана
* Шрифты остаются читаемыми

### Проверка на планшетах

**Разрешение 768x1024**

* Интерфейс переходит в промежуточный режим
* Карточки товаров отображаются корректно
* Фильтры работают корректно

### Проверка на десктопах

**Разрешение 1366x768**

* Все элементы интерфейса отображаются полностью
* Нет горизонтальной прокрутки
* Элементы управления доступны

**Разрешение 1920x1080**

* Интерфейс использует всю доступную ширину
* Нет потери функциональности
* Элементы остаются интерактивными

---

## Тестирование масштабирования

**Масштабирование 100%**

* Все элементы отображаются корректно
* Нет смещений и наложений

**Масштабирование 150%**

* Интерфейс сохраняет читаемость
* Нет потери функциональности
* Элементы остаются доступными

---

## Обнаруженные проблемы

* При масштабировании 200% наблюдается небольшое наложение элементов в форме поиска
* На разрешении 320x480 кнопки имеют минимальный размер, что может затруднять взаимодействие

## Рекомендации

* Оптимизировать отступы между элементами при масштабировании
* Увеличить минимальный размер интерактивных элементов для лучшего UX
* Проверить работу скролла на мобильных устройствах

## Вывод

Интерфейс демонстрирует хорошую адаптивность и корректную работу на различных устройствах. Обнаруженные проблемы не критичны и могут быть устранены минимальными изменениями в стилях.
